# Project 4：3DGS 导航

[English](README.md) | 简体中文

## 任务目标

自主采集并重建一个真实场景，在 3D Gaussian Splatting（3D-GS）场景中加入机器狗、目标点和障碍物。编写程序生成多条候选轨迹，选择其中一条，使机器狗沿该轨迹绕过障碍物并到达目标点，完成可运行、可复现的导航仿真。

## 基础要求

- **场景重建：** 使用课程设备或其他合适设备采集数据，自主调研公开的 3D-GS 方法完成重建，并将重建场景加载到自己的仿真或可视化程序中。
- **场景配置：** 通过自编脚本放置机器狗模型、起点、目标点及障碍物，支持通过参数或交互修改配置。至少设置一种障碍物阻挡起点至目标直线路径的情况。
- **轨迹规划：** 在具有可行路线的测试设置下，自动生成不少于 3 条具有明显差异的无碰撞候选轨迹，展示并比较其长度、安全间距等指标，说明选择其中一条的依据。
- **运动执行：** 编写轨迹执行逻辑，连续更新机器狗的位置和朝向，展示其沿选定轨迹绕障并到达目标的过程。考虑机器人尺寸，给出到达判定；不能仅画出路径或播放预先制作的动画。
- **测试分析：** 至少测试 3 组不同起点、目标点或障碍布局，修改配置后由程序重新规划。记录规划耗时、路径长度、到达误差和碰撞情况，分析主要问题及改进思路。

## 进阶要求

基础任务允许采用平面运动、已知机器人位姿和人工标注的可通行区域；用简化碰撞几何表示场景内主要障碍及新增障碍，并统一地图、机器人与重建场景的坐标。可通过位置和朝向更新模拟运动，不要求实现机器狗步态控制或完整 SLAM。

可使用公开的重建代码、渲染工具和已有机器人模型。基础任务须自主实现路径规划与轨迹执行的核心逻辑。进阶方案可选择自动建图、完整建图导航或动态避障等方向，并允许参考开源代码或采用现成导航框架；采用现成导航框架时，须明确说明自主开发或改进的模块，并提供相应的验证结果，不能仅运行现成示例完成作业。

## 工具选择

数据采集可使用课程提供的留形科技扫描仪，也可根据任务需要自行选择其他设备。场景重建须使用真实环境中自主采集的数据，不得以公开数据集、仿真数据或他人提供的现成场景模型替代。

## 提交材料

提交数据说明、重建模型、自编脚本及代码、配置和运行说明、导航演示视频，以及建议 4 至 6 页的实验报告。视频须展示场景配置、多条候选轨迹和机器狗执行过程；报告须说明算法选择、测试结果、自主工作及成员分工。
