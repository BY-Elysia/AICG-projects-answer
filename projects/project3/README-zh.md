# Project 3：CAD 智能体

[English](README.md) | 简体中文

开发一个将用户自然语言需求转化为可编辑三维 CAD 模型的智能体。智能体需要澄清需求、规划建模步骤、通过 [SimpleCADAPI（SCA）](https://github.com/PhySpace/SimpleCADAPI) 执行、检查结果，并在检查失败时修改模型，形成可运行、可复现的流程。

图片是任务示例。目前本目录只有作业说明，尚无提供的实现或构建配置。

## 基础任务

1. **理解需求。** 通过命令行或简单界面接收需求，提取结构、尺寸、单位和位置关系。关键条件缺失或冲突时，先询问用户，确认后再交付模型。
2. **规划与建模。** 由大模型规划步骤，通过工具调用或生成程序驱动 SCA。完成实体创建、布尔运算，以及拉伸、圆角、阵列等至少一种特征操作。关键尺寸须参数化。只返回代码或加载预制模型不算完成建模。
3. **检查与修正。** 检查生成实体是否有效，实测关键尺寸和位置关系，对照明确的验收条件判断结果。将执行报错或检查失败反馈给智能体并重新建模或修正，设置重试上限。程序没有报错不能作为模型正确的唯一依据。
4. **同一会话内修改。** 支持用自然语言修改尺寸或局部特征，保留未修改的需求。展示修改前后的模型，保存参数化建模源文件并导出 STEP 文件，保留对话、工具调用和执行反馈记录。
5. **测试分析。** 至少测试三组结构不同的建模需求，覆盖需求澄清、多轮修改和错误反馈修正。明确验收条件与尺寸容差，记录成功情况、尺寸偏差、运行耗时和修复次数，并分析失败原因。

例如，从“做一个放在桌上看视频的小支架”出发，可逐步确认设备尺寸、横竖放使用方式、支撑角度和充电避让缺口。需区分用户确定的参数与智能体建议的参数，并演示后续改参和检查过程。手机支架只是示例，不限定最终模型题材。

## 工具与任务边界

- CAD 建模必须使用 SCA。大模型可采用在线 API 或本地模型；界面和模型查看器自行选择，无需自研三维渲染器。
- 自主实现工具封装、建模流程控制和结果校验。可以参考 SCA 文档、Agent Skill 和开源智能体框架；采用框架时，须说明自主开发或改进的模块并提供验证结果。仅运行现成示例或现成 CAD 建模智能体不满足要求。
- 记录软件和模型版本；生成代码须在受限环境中执行，并设置执行超时。
- 基础任务可采用单智能体、单零件、纯文本输入方案，无需训练大模型、自研几何内核或实现复杂装配。进阶方向包括图文联合输入、装配建模及建模经验复用。模型复杂度也是评价因素之一。

## 提交材料

提交智能体代码、提示词与工具定义、测试需求与验收结果、参数化建模源文件及 STEP 模型、运行日志、配置与运行说明、演示视频，并建议附四至六页的实验报告。

视频应展示需求输入、自动建模、反馈修正和同一会话中的后续修改；报告应说明系统设计、测试结果、自主工作和成员分工。提交的实现需提供可复现的环境配置与运行方法，本说明不指定统一构建命令。
