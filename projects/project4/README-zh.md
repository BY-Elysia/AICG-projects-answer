# Project 4：3DGS 导航

[English](README.md) | 简体中文

自主采集真实环境数据，使用 3D Gaussian Splatting（3D-GS）重建场景，并在自己的仿真或可视化程序中加入机器狗、目标点和障碍物。程序需要规划无碰撞路线，让机器狗沿选定路线绕障到达目标，形成可运行、可复现的导航仿真。

图片是任务示例。目前本目录只有作业说明，尚无提供的实现或构建配置。

## 基础要求

1. **采集与重建场景。** 自主采集真实环境数据，调研并使用公开的 3D-GS 方法重建，再将结果加载到自己的仿真或可视化程序中。可使用课程设备或其他合适的采集设备；公开数据集、仿真数据或他人提供的现成场景不能替代自主采集的数据。
2. **配置仿真。** 编写脚本放置机器狗模型、起点、目标点和障碍物，支持通过参数或交互修改。至少设置一个障碍物阻挡起点至目标直线路径的场景，并统一地图、机器人和重建场景的坐标。
3. **规划并比较路线。** 在存在可行路线的测试设置下，自动生成至少三条具有明显差异的无碰撞候选轨迹。展示并比较路线长度、安全间距等指标，说明选取依据。碰撞检测须考虑机器人尺寸。
4. **执行选定轨迹。** 编写执行逻辑，连续更新机器狗的位置和朝向，展示其绕障并到达目标的过程；给出考虑机器人尺寸的到达判定。仅画出轨迹或播放预先制作的动画不满足要求。
5. **测试分析。** 至少测试三组起点、目标点或障碍布局不同的配置。每次修改配置后由程序重新规划，记录规划耗时、路径长度、到达误差和碰撞情况，分析问题与改进思路。

## 工具与任务边界

- 可以使用公开的重建代码、渲染工具和现成机器狗模型。基础任务的路径规划与轨迹执行核心逻辑须自主实现。
- 基础任务允许采用平面运动、已知机器人位姿、人工标注的可通行区域，以及表示主要场景障碍和新增障碍的简化碰撞几何；无需实现步态控制或完整 SLAM。
- 进阶方向包括自动建图、更完整的建图导航和动态避障。进阶方案可参考开源代码或采用现成导航框架，但须说明自主开发或改进的模块并提供验证结果；仅运行现成示例不满足要求。

## 提交材料

提交数据说明、重建模型、自编脚本与代码、配置与运行说明、导航演示视频，并建议附四至六页的实验报告。

视频应展示场景配置、多条候选轨迹及机器狗执行过程；报告应说明算法选择、测试结果、自主工作和成员分工。提交的实现需提供可复现的环境配置与运行方法，本说明不指定统一构建命令。
